# Agima project website

Static project page for *Planning with Agentic Imagination* (Agima).
Serve it with GitHub Pages from the repository root (`main` branch, `/`).

- `index.html`: the page
- `assets/css/styles.css`: styles (layout adapted from the RATs project page)
- `assets/js/main.js`: interactive results chart, reasoning table, Figure 1 highlight animation, rollout explorer
- `assets/images/`: paper figures (WebP) and `rollouts/` trajectory pages for the explorer
